# 🐍 Modern Snake Game

A beautiful, modern, and challenging twist on the classic Snake arcade game, built with React.

## Features
- Glassmorphism UI and responsive design
- Multiple levels with increasing obstacles
- Special food types with random effects (speed up, slow down, shrink, etc.)
- Pause and resume with keyboard shortcut
- Animated loading screen
- Professional landing and game pages
- Player name and level tracking
- Mobile-friendly and accessible

## Demo
[Live Demo Link](https://sn4ke-gam3.vercel.app/) 



## Getting Started

### Prerequisites
- Node.js (v16+ recommended)
- npm (v8+ recommended)

### Installation
```bash
npm install
```

### Running Locally
```bash
npm start
```
Visit [http://localhost:3000](http://localhost:3000) in your browser.

### Building for Production
```bash
npm run build
```


## Gameplay Instructions
- Use **Arrow Keys** to control the snake
- **P** to pause/resume
- Eat different food types for random effects
- Avoid obstacles and the snake's own body
- Level up by reaching the score threshold
- Click **Change Player** to restart with a new name
